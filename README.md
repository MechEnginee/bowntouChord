# 🎵 bowntouChord — 멜로디 자동 4성부(SATB) 화성 & 재생

멜로디 악보를 넣으면 **멜로디를 소리로 재생**하고,
각 음에 어울리는 **알토·테너·베이스(SATB 4성부) 화음까지 자동으로 붙여** 함께 들려주는 프로그램입니다.

```
악보 이미지 ──(OMR)──▶ MusicXML ──▶ 멜로디 ──(자동 화성)──▶ SATB ──▶ MIDI / WAV(소리)
```

- **입력**: 악보 이미지(.png/.jpg …), MusicXML, MIDI, 또는 간단한 텍스트 악보(.txt)
- **자동 화성**: 멜로디를 분석해 조성을 정하고, 각 음마다 어울리는 다이어토닉 코드(I·IV·V 등)를
  골라(비터비 DP로 진행을 자연스럽게) 소프라노(멜로디)/알토/테너/베이스로 배치
- **출력**:
  - `이름.wav` — 4성부 소리 (바로 재생 가능, 사운드폰트 불필요)
  - `이름.mid` — 4성부 MIDI (어떤 플레이어에서도 재생)
  - `이름.musicxml` — 4성부 악보 (MuseScore 등에서 열기)

---

## 설치

```bash
pip install -r requirements.txt
```

- `music21` : 필수 (악보 파싱·조성 분석·MIDI/MusicXML 입출력)
- `numpy`   : 권장 (WAV 합성 빠르고 스테레오). 없어도 순수 파이썬으로 동작
- `oemer`   : **악보 이미지**를 쓸 때만 필요한 OMR 엔진 → `pip install oemer`
  (최초 실행 시 인식 모델을 자동으로 내려받습니다.)

## 사용법

```bash
# 1) 텍스트 멜로디로 바로 화성 붙이기 (가장 간단·확실)
python -m satb examples/twinkle.txt -o out

# 2) 악보 이미지에서 자동 인식 후 화성 (oemer 설치 필요)
python -m satb 내악보.png -o out

# 3) MusicXML / MIDI 멜로디로 화성
python -m satb melody.musicxml -o out

# 만들고 바로 소리 재생 시도
python -m satb examples/twinkle.txt --play
```

주요 옵션:

| 옵션 | 설명 |
|------|------|
| `-o, --out` | 출력 파일 접두어 (기본: 입력 파일 이름) |
| `--play`    | 완성된 WAV 를 바로 재생 시도 |
| `--tempo N` | 템포(BPM) 강제 지정 |
| `--key`     | 조성 강제 지정 (예: `"C major"`, `"A minor"`) |
| `--no-wav`  | 소리(WAV) 생성 생략 |
| `--no-xml`  | 악보(MusicXML) 생성 생략 |

## 텍스트 악보 표기법

이미지가 없거나 OMR 정확도가 아쉬울 때, 멜로디를 직접 적을 수 있습니다.

```text
# '#' 로 시작하는 줄은 주석
key: C major        # (선택) 조성. 생략하면 자동 추정
tempo: 100          # (선택) BPM. 생략하면 90

C4:1 C4:1 G4:1 G4:1 A4:1 A4:1 G4:2   # '계이름옥타브:박자'
```

- **음이름**: `C D E F G A B`, 임시표는 `#` 또는 `b` (예: `F#4`, `Bb3`)
- **옥타브**: 가온다 = `C4`
- **박자**: 4분음표 `1`, 2분음표 `2`, 8분음표 `0.5`, 점4분음표 `1.5`
- **쉼표**: `R:박자` (예: `R:1`)

예시는 [`examples/twinkle.txt`](examples/twinkle.txt) 참고.

## 화성이 만들어지는 원리 (요약)

1. **조성 결정** — `key:` 지정이 있으면 그대로, 없으면 `music21` 로 멜로디에서 자동 추정
2. **코드 선택** — 각 멜로디음을 코드톤으로 포함하는 다이어토닉 3화음 후보 중에서,
   코드 우선순위(1차 3화음 I·IV·V 선호) + 기능 진행 규칙(예: 도미넌트→토닉 선호,
   도미넌트→서브도미넌트 회피)을 점수로 삼아 **비터비 DP** 로 전체 진행을 최적화.
   시작은 토닉, 끝은 토닉(V–I 종지)으로 유도.
3. **성부 배치(voicing)** — 소프라노=멜로디로 고정하고, 근음 중복 관례에 따라
   알토·테너·베이스를 각 성부 음역 안에서 배치. 성부 교차 금지, 넓은 간격/큰 도약을
   벌점으로 삼아 **성부진행이 매끄럽도록** 최적 배치를 선택.

## 프로젝트 구조

```
satb/
  ├─ melody.py   입력(이미지결과/MusicXML/MIDI/텍스트) → 멜로디
  ├─ harmony.py  자동 화성 엔진 (코드 선택 + SATB 배치)   ← 핵심
  ├─ synth.py    4성부 → WAV 소리 합성 (외부 신디사이저 불필요)
  ├─ export.py   4성부 → MIDI / MusicXML
  ├─ omr.py      악보 이미지 → MusicXML (oemer 래퍼)
  └─ cli.py      명령줄 진입점
examples/
  └─ twinkle.txt 예시 멜로디
```

## 참고

- 악보 이미지 자동 인식(OMR)은 본질적으로 오류가 있을 수 있습니다. 정확도가 중요하면
  MuseScore 등으로 이미지를 열어 **MusicXML 로 저장한 뒤 입력**하는 방법을 권장합니다.
- 현재 자동 화성은 **다이어토닉 3화음** 범위에서 동작합니다(7화음·전조·비화성음 세부 처리는 향후 확장 여지).
